# Open Source Solutions Search Strategies

오픈소스 서비스/솔루션/템플릿을 효과적으로 찾는 검색 전략.

## 검색 목표

**"이미 만들어진 것"을 찾아서 개발 시간 단축!**

찾는 대상:
- 완성된 오픈소스 서비스 (Medusa, Strapi 등)
- 기능 모듈 (인증, 결제, 채팅 등)
- 시작 템플릿/보일러플레이트

---

## 검색 쿼리 패턴

### 유사 서비스 찾기

```
# 유명 서비스 대안 찾기
"{서비스명} open source alternative"
"{서비스명} self hosted"
"open source {서비스명} clone"

# 예시
"notion open source alternative"
"shopify open source alternative"
"slack self hosted alternative"
"figma open source clone"
```

### 카테고리별 찾기

```
# 서비스 유형으로 검색
"open source {서비스유형} 2025"
"best self hosted {서비스유형}"
"awesome {서비스유형} self hosted"

# 예시
"open source ecommerce 2025"
"best self hosted crm"
"awesome analytics self hosted"
```

### 기능 모듈 찾기

```
# 특정 기능 솔루션
"open source {기능} solution"
"self hosted {기능} service"
"{기능} as a service open source"

# 예시
"open source authentication solution"
"self hosted notification service"
"search as a service open source"
```

## 유형별 검색 전략

### 이커머스/쇼핑몰

```
# 검색어
"open source ecommerce platform"
"shopify alternative open source"
"headless commerce open source"
"medusa vs saleor vs vendure"

# 주요 프로젝트
- Medusa (Node.js, headless)
- Saleor (Python/Django, GraphQL)
- Vendure (TypeScript, headless)
- Shuup (Python/Django)
- Bagisto (Laravel/PHP)
```

### CMS (콘텐츠 관리)

```
# 검색어
"headless cms open source"
"strapi alternative"
"open source cms node.js"
"best self hosted cms 2025"

# 주요 프로젝트
- Strapi (Node.js, 가장 인기)
- Payload (TypeScript, 최신)
- Directus (Vue + Node.js)
- Ghost (Node.js, 블로그 특화)
- KeystoneJS (GraphQL)
```

### 채팅/메시징

```
# 검색어
"slack alternative open source"
"self hosted team chat"
"open source messaging platform"
"discord alternative self hosted"

# 주요 프로젝트
- Rocket.Chat (가장 기능 풍부)
- Mattermost (기업용, Slack 대안)
- Zulip (스레드 기반)
- Element/Matrix (분산형)
```

### 프로젝트 관리

```
# 검색어
"jira alternative open source"
"notion alternative open source"
"project management self hosted"
"open source kanban board"

# 주요 프로젝트
- Plane (Jira 대안, 현대적)
- Focalboard (Notion 대안, Mattermost)
- Taiga (애자일/스크럼)
- OpenProject (엔터프라이즈급)
- WeKan (칸반 보드)
```

### 분석/대시보드

```
# 검색어
"google analytics alternative open source"
"self hosted analytics"
"open source business intelligence"
"metabase alternative"

# 주요 프로젝트
- Plausible (간단, 프라이버시)
- Umami (가볍고 빠름)
- Matomo (GA 완전 대안)
- Metabase (BI, 시각화)
- PostHog (제품 분석)
```

### 인증/보안

```
# 검색어
"open source identity management"
"keycloak alternative"
"self hosted authentication"
"open source sso solution"

# 주요 프로젝트
- Keycloak (가장 완성도 높음)
- Authentik (현대적 UI)
- Logto (개발자 친화적)
- Ory (모듈형)
- SuperTokens (간단한 인증)
```

### 폼/설문

```
# 검색어
"typeform alternative open source"
"self hosted form builder"
"open source survey tool"

# 주요 프로젝트
- Formbricks (현대적, 인앱 설문)
- Typebot (챗봇 형식)
- LimeSurvey (전통적 설문)
- OhMyForm (간단한 폼)
```

### AI/LLM 관련

```
# 검색어
"chatgpt ui open source"
"open source llm interface"
"self hosted ai chat"
"langchain ui open source"

# 주요 프로젝트
- Open WebUI (ChatGPT 대안 UI)
- LibreChat (다양한 LLM 지원)
- Flowise (LangChain UI)
- Langflow (시각적 LLM 빌더)
- PrivateGPT (로컬 문서 질문)
```

## GitHub 검색 팁

### 고급 검색

```
# 스타 수로 필터링
stars:>5000 topic:ecommerce

# 최근 업데이트된 것만
pushed:>2024-01-01 topic:cms

# 특정 언어로 필터링
language:typescript topic:dashboard stars:>1000

# 조합
stars:>2000 pushed:>2024-06-01 topic:self-hosted
```

### Topic 태그 활용

인기 있는 self-hosted 관련 토픽:
- `self-hosted`
- `selfhosted`
- `open-source`
- `headless-cms`
- `ecommerce`
- `project-management`
- `team-chat`

---

## 품질 체크 순서

1. **GitHub Stars 확인**: 1,000+ 권장
2. **최근 커밋 확인**: 6개월 내 활동
3. **이슈 응답률**: 메인테이너 활성도
4. **문서화**: README, 공식 문서 사이트
5. **라이선스**: 상업용 가능 여부
6. **데모/플레이그라운드**: 직접 사용해보기

## 한국 서비스 특화

한국에서 필요한 기능이 있는 오픈소스:

```
# 결제 연동
"korean payment gateway integration"
"toss payments open source"

# 카카오 연동
"kakao login open source"
"kakao api integration"

# 네이버 연동
"naver login integration"
"naver map open source"
```

**주의**: 한국 특화 기능(토스, 카카오, 네이버)은 글로벌 오픈소스에 없는 경우가 많음.
→ 이 경우 "기본 오픈소스 + 한국 연동 직접 개발" 전략 필요
